## Course objectives

The key components of multimedia are text, audio, image, vector graphics and
video. The course discusses the characteristics of these individual components
together with applications of intelligent multimedia information retrieval.

## Course description

- Become familiar with multimedia components and acquire the ability to develop software components that process multimedia data (text, audio, image).
- Establish a basic understanding of multimedia systems, in order to identify, formulate and solve computer/information engineering problems using multimedia data.
- Build programming skills for handling multimedia data.
- Establish a broad understanding of the impact of engineering solutions in society.
