THE BYTE DETECTIVE

  one real payment · 225 bytes · you read every one of them
  SOC4190 · LECTURE 6




  The payment below is real. It sits in Bitcoin block 968,391 (24 Sep 2026) and moved 1,000,000 satoshi.
  Nodes never see a picture of it, only its 225 bytes. In five missions you read those bytes the way a node does:
  backwards where needed, field by field, and at the end you compute its transaction ID yourself.









The lesson. A transaction is not a form with names on it. It is a row of bytes: a version, one input
(which old output it spends, and the key that opens it), outputs (an amount and a lock each) and four closing bytes. Numbers are
stored smallest byte first. The transaction ID is nothing but SHA-256 of those bytes, twice (for a SegWit payment: the bytes without the witness). Nobody assigns it.
