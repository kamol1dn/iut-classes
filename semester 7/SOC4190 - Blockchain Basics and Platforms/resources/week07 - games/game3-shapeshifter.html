THE SHAPESHIFTER

  same payment, two names · malleability, Mt. Gox and the fix
  SOC4190 · LECTURE 6




  The transaction ID is the hash of the bytes — and the signature sits inside those bytes. The signature cannot sign itself, so a
  stranger can rewrite it (without breaking it) and give the same payment a new ID before it reaches a block.
  You will do that to our real payment, run a withdrawal desk that trusts IDs, and then move the signature where it can do no harm: the witness.









The lesson. Before a payment is in a block, its ID is a name that someone else can change. Track what a payment
does (which coin it spends), not what it is called. SegWit moves signatures out of the hashed bytes into a witness section, so the ID
can no longer be changed this way — and the Mt. Gox story reminds us that a real flaw is not automatically the cause of a real loss.
